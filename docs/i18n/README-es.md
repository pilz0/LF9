## 🏰 Prólogo: El Nacimiento de un Reino Digital

Hace mucho tiempo, en los reinos etéreos de Lernfeld 9, los antiguos maestros de la tecnología previeron la necesidad de un gran reino educativo donde los buscadores de conocimiento pudieran aprender las artes de la infraestructura moderna. Así comenzaron las crónicas de LF9 - un cuento de once seres digitales extraordinarios, cada uno con poderes y propósitos únicos, que se unirían para formar el entorno de aprendizaje más completo jamás creado.

El reino se extiende a través de la red mística de `10.13.12.0/24`, donde los reinos IPv4 e IPv6 coexisten en perfecta armonía bajo la subred `fd69:acab:1312::/64`. Cada habitante posee su propio dominio sagrado, accesible a través de puertos antiguos e invocaciones DNS místicas.

## 🌟 Capítulo 1: La Gran Invocación

*"Que haya contenedores", dijeron los antiguos maestros DevOps, y así comenzó la mayor aventura educativa conocida por la humanidad digital.*

En el principio, había caos - un mundo donde las aplicaciones corrían salvajemente, consumiendo recursos sin restricción, comunicándose a través de protocolos misteriosos que solo los administradores de sistemas más experimentados podían descifrar. Pero de este caos surgió una visión: **El Reino LF9**, un reino armonioso donde once entidades poderosas trabajarían juntas para enseñar las artes sagradas de la infraestructura moderna.

La Gran Invocación comienza con tres encantamientos místicos:

### 🪄 El Hechizo de Inicio Rápido (Para Aventureros Impacientes)

```bash
git clone https://github.com/pilz0/LF9
cd LF9
./manage.sh setup    # Prepara los artefactos sagrados
./manage.sh validate # Consulta los oráculos digitales
./manage.sh start    # Da vida al reino
```

*"Con estos tres comandos, incluso el aventurero más novato puede invocar todo el reino a la existencia, viendo como once almas digitales cobran vida en perfecta armonía."*

### 🧙‍♂️ La Invocación Tradicional (Para Académicos Pacientes)

Para aquellos que desean entender los rituales antiguos:

```bash
# 1. Adquiere los textos sagrados
git clone https://github.com/pilz0/LF9
cd LF9

# 2. Personaliza la configuración mística
cp .env.example .env
nano .env  # Inscribe tus contraseñas secretas

# 3. Despierta los espíritus digitales
docker compose up -d

# 4. Presencia como el reino cobra vida
docker compose ps
```

### ⚡ Requisitos Previos para el Viaje

Antes de poder invocar el Reino LF9, uno debe preparar su recipiente terrenal:

- **Una Fortaleza Linux Moderna**: ~4GB RAM, 15GB almacenamiento, 2 núcleos CPU
- **El Encantamiento Docker**: Runtime de magia de contenedores
- **Alquimia Docker Compose**: Poderes de orquestación de servicios
- **Maestría Git**: Sabiduría de control de versiones

**Para Reinos Ubuntu/Debian:**
```bash
sudo apt install docker.io docker-compose-plugin git
```

## ⚔️ Capítulo 2: El Consejo de Servicios

*"Once hay, y once habrá siempre - cada uno con su propósito sagrado, cada uno esencial para el gran diseño."*

En el gran salón de `docker-compose.yml`, se reúne el Consejo de Servicios. Cada miembro aporta habilidades únicas que, cuando se combinan, crean un entorno educativo de poder sin precedentes:

### 🏛️ El Círculo Interno (Servicios Core)

1. **WordPress el Tejedor de Contenido** (Puerto 8080) - *Maestro de la publicación digital y creación de contenido*
2. **Grafana el Oráculo Omnividente** (Puerto 3000) - *Guardián de métricas y sabiduría de tableros*
3. **Unbound el Guardián DNS** (Puerto 53) - *Resolvedor de nombres y guardián de la verdad de red*

### 🗄️ Los Guardianes de Datos

4. **MariaDB el Guardián de Base de Datos** (Puerto 3306) - *Protector del contenido sagrado de WordPress*
5. **PostgreSQL la Bóveda del Conocimiento** (Puerto 5432) - *Guardián de la sabiduría acumulada de WikiJS*

### 📁 Los Guardianes de Archivos

6. **FTP el Antiguo Pastor de Archivos** (Puertos 20-21) - *Maestro de las artes tradicionales de transferencia de archivos*
7. **Samba el Sabio de Archivos de Red** (Puertos 139, 445) - *Tejedor de la magia de compartir archivos en red*

### 🖥️ Los Magos de Apoyo

8. **VNC el Sabio del Escritorio Virtual** (Puertos 5901, 6901) - *Creador de reinos visuales remotos*
9. **WikiJS el Cronista del Conocimiento** (Puerto 3001) - *Registrador de toda la sabiduría digital*
10. **Prometheus el Recolector de Métricas** (Puerto 9090) - *Recopilador de perspectivas de rendimiento*
11. **Node Exporter el Vigilante del Sistema** (Puerto 9100) - *Observador del reino subyacente*
