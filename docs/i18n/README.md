## 🎯 What is LF9? | Was ist LF9? | Какво е LF9?

**English**: The LF9 Kingdom is a comprehensive multi-service Docker learning environment designed for educational purposes (Lernfeld 9). It features 11 interconnected services that teach modern infrastructure concepts through an engaging fantasy narrative.

**Deutsch**: Das LF9-Königreich ist eine umfassende Multi-Service-Docker-Lernumgebung, die für Bildungszwecke (Lernfeld 9) entwickelt wurde. Es verfügt über 11 miteinander verbundene Dienste, die moderne Infrastrukturkonzepte durch eine fesselnde Fantasy-Erzählung vermitteln.

**Български**: Кралството LF9 е всеобхватна многосервизна Docker обучителна среда, предназначена за образователни цели (Lernfeld 9). То включва 11 взаимосвързани услуги, които преподават концепции за модерна инфраструктура чрез увлекателна фантастична история.

## 🏰 The Digital Kingdom Services | Die Digitalen Königreich-Dienste | Услугите на Цифровото кралство

### Core Services | Kerndienste | Основни услуги
- **WordPress** - Content Management | Inhaltsverwaltung | Управление на съдържание
- **Grafana** - Monitoring Dashboard | Überwachungs-Dashboard | Табло за мониторинг
- **Unbound** - DNS Resolution | DNS-Auflösung | DNS резолюция

### Data Guardians | Datenwächter | Пазители на данни
- **MariaDB** - Database for WordPress | Datenbank für WordPress | База данни за WordPress
- **PostgreSQL** - Database for WikiJS | Datenbank für WikiJS | База данни за WikiJS

### File Services | Dateidienste | Файлови услуги
- **FTP Server** - File Transfer | Dateiübertragung | Файлов трансфер
- **Samba** - Network File Sharing | Netzwerk-Dateifreigabe | Мрежово споделяне на файлове

### Support Services | Unterstützungsdienste | Поддържащи услуги
- **VNC** - Virtual Desktop | Virtueller Desktop | Виртуален работен плот
- **WikiJS** - Documentation | Dokumentation | Документация
- **Prometheus** - Metrics Collection | Metriken-Sammlung | Събиране на метрики
- **Node Exporter** - System Monitoring | Systemüberwachung | Системен мониторинг

## 🚀 Quick Start in Any Language | Schnellstart in jeder Sprache | Бърз старт на всеки език

```bash
# Universal commands work in all languages
git clone https://github.com/pilz0/LF9
cd LF9
./manage.sh setup
./manage.sh validate  
./manage.sh start
```

### Access the Kingdom | Zugang zum Königreich | Достъп до кралството
- **WordPress**: http://localhost:8080
- **Grafana**: http://localhost:3000
- **VNC Desktop**: http://localhost:6901
- **WikiJS**: http://localhost:3001
